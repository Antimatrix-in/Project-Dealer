# UPWORKS – Project Development Services

Official repository for **UPWORKS – Project Development Services** web platform.

Premier academic project development, complete documentation, and 1-on-1 viva defense mentorship for engineering and computer science students.

## Brand Identity & Theme

- **Brand Name:** UPWORKS
- **Tagline:** PROJECT DEVELOPMENT SERVICES
- **Palette:**
  - Navy Blue: `#101D38` (Headers, navigation, headings)
  - Orange: `#F58216` (Primary action buttons, highlights, badges)
  - White: `#FFFFFF` (Main backgrounds, cards)
  - Light Grey: `#F4F6FA` (Section backgrounds, subtle fills)
  - Slate: `#263750` (Body text, secondary elements)
  - Light Border: `#DCE2EA` (Card borders, dividers)

## Features

- **16 Technical Domains:** AI & Machine Learning, Deep Learning, Python, Java Spring Boot, Cloud Computing, Cyber Security, Web & Mobile App Development, and more.
- **Direct Navigation:** Consultation and service enquiry buttons route directly to official UPWORKS WhatsApp helpline (`+91-9159514326`).
- **Google Form Integration:** Custom requirement submission flows route directly to the official Google Form (`forms.gle/oKyzxdmdVZLwWWmU6`).
- **Responsive Architecture:** Clean desktop and mobile responsive layout built with Next.js 16 (Turbopack), React 19, and Tailwind CSS.
- **Admin Dashboard:** Secure portal for reviewing student applications and inquiry logs.

## Tech Stack
- **Framework**: Next.js (App Router)
- **UI & Styling**: Tailwind CSS, Lucide Icons, Framer Motion
- **Hosting**: Vercel (`https://project-dealer-vm3u.vercel.app/`)

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5001](http://localhost:5001) in your browser.

## Build & Production

Create an optimized production build:

```bash
npm run build
npm run start
```

## Deployment

Configured for automatic deployment to Vercel at `https://project-dealer-vm3u.vercel.app/` with Next.js framework configuration.
